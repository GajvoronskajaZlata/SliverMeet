# Проект: Графическое приложение «Currency Converter»

**Автор:** Имя Фамилия (9 класс)

## Описание проекта
Программа представляет собой конвертер валют с графическим интерфейсом (GUI), написанный на языке Python с использованием библиотеки `CustomTkinter`. Программа позволяет переводить суммы между популярными мировыми валютами, сохраняет историю операций в файл JSON и имеет резервный оффлайн-режим.

## Основные возможности
* Конвертация в реальном времени между валютами: USD, EUR, RUB, GBP, JPY, CNY, KZT, BYN.
* Защита от некорректного ввода (проверка на отрицательные числа, буквы и пустые поля).
* Автоматическое сохранение последних 50 конвертаций в файл `history.json`.
* Автоматическая установка недостающих библиотек при первом запуске скрипта.
* **Умный оффлайн-режим:** Если сервер API недоступен или заблокирован брандмауэром, приложение автоматически переключается на встроенную резервную базу курсов (программа напишет "Результат (оффлайн)").

## Как запустить проект
1. Установите Python версии 3.8 или выше.
2. Скачайте файл скрипта.
3. Запустите файл через терминал или среду разработки (например, VS Code). Все необходимые библиотеки (`customtkinter`, `requests`) установятся автоматически при первом старте.

## Работа с API
Программа настроена на работу с полностью бесплатным и открытым API-сервером `://er-api.com`. 
* Регистрация и получение токенов/ключей **не требуются**.
* Запросы отправляются по адресу: `https://://er-api.com/v6/latest/{валюта}`

## Примеры использования (Тесты)
1. **Тест на корректность**: Выбираем USD -> RUB, вводим сумму `100`. Нажимаем "Конвертировать". В поле выводится актуальная сумма в рублях, запись добавляется в таблицу справа.
2. **Тест валидации (Буквы)**: Вводим в поле суммы текст `abc`. Программа выдает окно с ошибкой "Сумма должна быть положительным числом!".
3. **Тест валидации (Минус)**: Вводим сумму `-50`. Программа выдает предупреждение об ошибке.
